# Неон Арена — стрелялка с другом (Unity)

3D-шутер от первого лица. Лобби, магазин оружия и скинов, 4 локации, бои от 1 VS 1 до 5 VS 5 с другом и ботами.

**Играть в браузере (телефон или компьютер):** https://vamshopkz.github.io/neon-arena/
**Android APK:** https://github.com/vamshopkz/neon-arena/releases/latest/download/NeonArena.apk

## Как играть с другом
1. Оба открывают игру и вводят ник.
2. Один нажимает **ОТРЯД** — там его код (например `JFHD49`). Он говорит код другу.
3. Друг нажимает **ОТРЯД**, вводит код и **ВОЙТИ** — теперь вы в одном лобби и видите друг друга.
4. Кто-нибудь встаёт в портал **1 VS 1 … 5 VS 5**. **У обоих на экране появляется выбор локации**:
   Пустыня, Лабиринт, Стадион, Лес. Каждый нажимает, где хочет играть (15 секунд).
   Больше голосов — та локация; поровну — случайная из выбранных.
5. Лидер отряда выбирает: «друг против друга» или «вместе против ботов». Свободные места занимают боты.

## Что есть
- **Лобби** (по картинке 1): неоновый зал с порталами 1 VS 1 … 5 VS 5, круглый зал со звёздным полом,
  изогнутые коридоры с граффити, **магазин оружия** (витрины с оружием) и **тир** с мишенями.
- **Локации**: Пустыня (каньон, два дома с лестницей на второй этаж, укрытия),
  Лабиринт (новый каждый бой), Стадион (футбольное поле с укрытиями, **гол мячом = +3 очка**),
  Лес (ёлки, деревянные заборы, палатка, **аптечки** +50 здоровья).
- **Оружие** (по картинке 6): АК-74, СВД и винтовка Мосина (с оптикой), РПГ-7, ТТ, Glock 17, Кольт 1911,
  нож КА-БАР, нож-бабочка, сюрикены, кунаи, метательный топор, граната Ф-1.
- **15 скинов** на каждое оружие: цифровой камуфляж, гравировка по дереву, пиксель-арт, стикербомба,
  микросхема, нефрит, лава, дамасская сталь, обсидиан, черепа, углепластик, радуга, космос, золото.
  **У каждого оружия и каждого скина своя цена.** Друг видит твой скин в бою.
- **Аптечки в магазине** (раздел «Аптечки»): +10 ХП — 40 монет, +50 ХП — 180, +100 ХП — 400.
  Покупаешь в запас, в бою лечишься клавишами 6 / 7 / 8 или кнопками над полоской здоровья.
- **Прицел на каждом оружии**: правая кнопка мыши (на телефоне — кнопка ПРИЦЕЛ). Пока прицел включён,
  наведи его на соперника — он станет красным, и оружие **выстрелит само**. Без прицела автострельбы нет.
  В тире можно попробовать на мишенях.
- **Монеты**: 1000 на старте, +25 за врага, +150 за победу, +30 за гол.
- Управление: ПК — WASD, мышь, ЛКМ огонь, ПКМ прицел (с автовыстрелом), R, 1–5, 6/7/8 аптечки, Shift, Пробел, E — магазин, Tab — счёт;
  телефон — джойстик, обзор пальцем, кнопки ОГОНЬ / ПРЫЖОК / R / ПРИЦЕЛ.
- Сеть — через бесплатные интернет-реле (MQTT), нужен только интернет; телефон и браузер играют вместе.

## Сборка
Unity 6000.3.21f1, всё строится из кода (`UnityProject/Assets/Scripts`).
- `./build_and_test.sh DIR` — сборка для Mac + автотест (44 проверки + скриншоты).
- `./mp_test.sh DIR` — две копии игры через интернет: лидер и друг, голосование, бой.
- `./release.sh 1.1 "что нового"` — APK в GitHub Releases.
- `BuildScript.BuildWebGL`, затем `./publish_web.sh` — браузерная версия на GitHub Pages.
